# ✨ Text Studio

A modern, interactive text editing and typography tool designed to make working with text simple, fast, and stylish.

**Devex Text Studio** lets you transform text, customize typography, analyze text statistics, and export your work through a clean, responsive interface with a dark purple aesthetic and vibrant gradient effects.

## 🚀 Features

### 📝 Text Editor
- Write or paste text directly into the editor.
- Instantly track characters, words, and sentences.
- Estimate reading time based on word count.

### 🎨 Typography Customization
- Choose from multiple font families.
- Adjust font size and weight.
- Customize text color using a color picker or HEX code.
- Apply italic styling.
- Change text alignment: left, center, right, or justify.
- Adjust line height and letter spacing.
- Copy generated CSS styles to your clipboard.

### 🔄 Text Transformation
Transform your text instantly with the following tools:

- **UPPERCASE**: Convert text to uppercase.
- **lowercase**: Convert text to lowercase.
- **Title Case**: Capitalize words appropriately.
- **Sentence Case**: Format text as sentences.
- **Slugify**: Convert text into URL-friendly slugs.
- **Markdown to Plain Text**: Remove common Markdown formatting.
- **Trim Extra Spaces**: Clean unnecessary spaces and line breaks.
- **Reverse Text**: Reverse the character order.

### 📋 Export and Clipboard
- Copy transformed text to the clipboard.
- Download text as a `.txt` file.
- Clear the editor instantly.
- Receive visual feedback for completed actions.

### 💜 Modern User Interface
- Elegant dark theme with purple, cyan, and pink accents.
- Animated gradient branding and ambient background effects.
- Glassmorphism-inspired cards.
- Responsive layout for different screen sizes.
- Interactive controls and smooth hover effects.

## 🛠️ Technologies Used

- **HTML5**: Application structure.
- **CSS3**: Styling, animations, gradients, and responsive design.
- **JavaScript**: Text transformations, typography controls, clipboard operations, and statistics.
- **Google Fonts**: Enhanced typography using Inter, Poppins, Roboto, Montserrat, Playfair Display, Merriweather, and Courier Prime.

## 💻 Getting Started

### Prerequisites

- A modern web browser.
- An internet connection for loading Google Fonts.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/BenkabaMarwa/text-studio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd text-studio
   ```

3. Open `index.html` in your browser.

Alternatively, download the repository as a ZIP file and open `index.html` directly.

**No package installation or build process is required.**

## 🎯 Use Cases

Devex Text Studio can help with:

- Preparing and formatting text for websites and social media.
- Generating URL-friendly slugs for blog posts and web pages.
- Cleaning Markdown-formatted text.
- Testing typography styles before implementing them in a website.
- Generating reusable CSS typography declarations.
- Analyzing word counts and estimated reading time.

## 🔒 Privacy

Text processing takes place directly in your browser. The application does not require an account or a backend server to perform its core features.

Google Fonts requires an internet connection to load the selected online fonts.
